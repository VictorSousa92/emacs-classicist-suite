The classicist suite for Emacs

Tools for reading Greek and Latin: Diogenes’ corpora and lexica, the printed dictionaries, the Diorisis corpus of lemmatised Greek, treebank annotation, editions published as TEI, and notes in org.

Two things, on two tabs. Configuration is what is true of this machine — which features you want awake, where the corpora and dictionaries are, which viewer opens a scan, which keys you want — and it writes the block for your init file. Presets is what varies with what you are doing: where the windows go, how much room each gets, how much of an entry to show. It writes a file you can load and change without touching your init file.

Where to start

The whole suite is installed either way; these decide what it does. Everything not chosen is loaded and asleep: no keys, no menu entries, nothing offered.

 

Fixes only is the corrections this package makes, and nothing that changes how Diogenes looks: a word hyphenated across a line can be looked up, the lemma prompt completes on the corpus's own lemmata, every entry of a homograph is shown rather than the first, the windows stay wherever you have arranged them, and a Diogenes buffer is claimed by the perspective it appears in so that previous-buffer can reach it. It is not Diogenes as it was — it is Diogenes without its rough edges.

The features

What is awake. classicist-features — and three of the eight want another: the printed dictionaries are a banner on a lexicon entry, the treebank annotates Diorisis sentences, and a note is about a passage in some browser. Ticking one ticks what it wants.

No Diogenes CD-ROMs? The Diorisis corpus and the TEI editions want none of that data — both read their own. Tick those two, set two paths below, and leave diogenes-path empty.

classicist-morpheus-directory — for forms the wordlists never saw. Optional.

What needs something else. A scanned dictionary wants pdf-tools, and its page cannot be shown without it. A dictionary wants its path, and until it has one its key says what to set rather than doing nothing. The note commands want org-roam, the frame keys want nothing, and the evil key wants evil. All of it wants the base, and M-x classicist-check-base says whether yours will do. Passage notes filed by author and work are a package of their own: diogenes-roam, branch classicist-roam. Nothing here depends on anything else here: no setting below turns another one off.

Dictionaries

A dictionary appears when its path is set and the file is there; an empty path means one fewer dictionary rather than a broken one. The key box shows the default — fill it only to change it, or type - to bind nothing.

Tick a dictionary to declare it (classicist-declared-dictionaries): it is then offered on every entry of its language whatever its paths say, and pressing its key explains what to set. Worth ticking one you are about to install, or one whose files are somewhere this check cannot see. Leave it unticked and the paths decide, which is what most people want.

The key boxes here are the dictionary letters, and the same caution applies to them as to the keys further down: check each one in your own Emacs before settling on it. Open a Diogenes entry, press C-h k and the key, and Emacs names whatever holds it. What this tool knows is a curated list and cannot include your own packages or bindings.

Copy a file in your file manager and paste it into a box — the clipboard carries the whole path and the box takes it, on Windows, macOS and Linux alike. Typing works too. Dragging works in some browsers: most now withhold the path of a dropped file, the same rule that hides it in a file chooser, and the box says so when that happens. Nothing is uploaded anywhere.

On Windows, Copy as path in Explorer's right-click menu (hold Shift) gives what these boxes want. Backslashes are turned into forward slashes, which Emacs accepts and which keeps the generated configuration readable.

One folder for them all, if they share one type it once and a name is enough in each box below — OLD.pdf, TLL/. A path that begins with a slash, a ~ or a drive letter is left alone, so a dictionary kept somewhere else still works. The boxes keep what you type; the joining happens in the block, so moving this moves them all.

Reading

Which viewer opens a scanned dictionary — diogenes-old-pdf-viewer. The keys it takes for itself are checked against yours below.

Where a citation opens

An entry is full of citations, and three places may hold the passage: the corpus itself, a TEI edition, or the Diorisis sentences. Tried in order, each saying whether it has the passage rather than opening something else — so a citation leads somewhere or says which path to set. Left as they are, these follow the corpora you have set above.

Greek citations classicist-lookup-open-greek-with — all three are open to Greek
Latin citations classicist-lookup-open-latin-with — two only: the Diorisis corpus is Greek

How it behaves

All seven are on. The first three change what you see the moment you open a text; the rest are fixes, or are invisible until used.

The corpora published as TEI

Where the editions are tei-directory — the directory holding canonical-greekLit, canonical-latinLit, First1KGreek or the like, and the index tei-index.py wrote there.
The reading script, if you installed rather than cloned tei-read-script — tei-read.py, which a package manager leaves in its checkout rather than its build: straight puts it under straight/repos/ while the package looks in straight/build/. Empty if you cloned the repository, where it is found beside the elisp.

The Diorisis corpus

The database diorisis-database — diorisis.db, made by diorisis-index.py from the corpus's own XML. Ten million lemmatised words of Greek literary prose and verse.
A merged database, if you have one diorisis-merged-database — the same corpus with more columns on it. Bilby's DuckDB compilation carries what Diorisis does not expose -- the morphology decomposed into a column per category, the dialect, the prosody -- and tools/diorisis-merge-duckdb.py writes those onto a copy. Ours is the spine, theirs is carried across: theirs has no citation, and a hit must stay a passage you can open.
Which Diogenes corpus its numbers belong to diorisis-corpus — the TLG, and there is no other answer -- Diorisis is Greek filed under the TLG's own author and work numbers, which is what lets a hit be opened in the browser. A box rather than a constant because a reader with a custom corpus of the same texts may want to say so.
Where searches are kept diorisis-saved-directory — a saved search is a file here, and M-x diorisis-search-saved reads them back.

The treebank

Where the trees are written treebank-directory — one file per sentence, as ALDT or CoNLL-U.
Where workbooks are kept treebank-workbook-directory — a workbook is the sentences collected from a search, to annotate together.
The viewer's own page treebank-viewer-directory — where index.html and Arethusa's files are, if Emacs serves them.
Arethusa's source, if you have it treebank-arethusa-directory — a checkout of github.com/alpheios-project/arethusa, if you have one -- the viewer then loads from your tree rather than from the copy npm fetched into tools/viewer.
The port the viewer listens on treebank-viewer-port — 8087 by default, and used either way: where Emacs starts the server, or where it expects to find one already answering. It checks before starting, so a viewer you run yourself is left alone.

Notes in org

The link type a passage gets diogenes-org-link-type — classicist by default, so a note's ROAM_REFS reads classicist:tlg:0086:...
The subdirectory in your roam diogenes-roam-subdirectory — ref by default, so a note lands under ref/author/work/
The tag every passage note gets diogenes-roam-tag — passage by default
What to call an author diogenes-roam-name-overrides — the corpora name an author at length: 0086 of the TLG is Aristoteles Phil. et Corpus Aristotelicum, Aristotle (0086), and a directory wants one word. The first word is taken unless you say otherwise here. Four rows is enough for the authors you read often; beyond that the option takes any number, written by hand.
What a note's file is called diogenes-roam-file-name — the author and work are in the path already, so the name need not repeat them
The index file diogenes-roam-index-name — index.org by default
How wide a snippet in the index diogenes-roam-index-snippet-width — 88 by default
Which edge it sits on diogenes-roam-index-side — right by default. defer hands the placing to the suite, where a preset can make it — the index otherwise puts itself in a side window, which no preset reaches, so split and frames say nothing about it
How much room it takes diogenes-roam-index-size — 0.35 by default — a fraction of the width at the right or left, of the height otherwise. A whole number is columns or lines instead
Where a note opens when followed diogenes-roam-index-open-in — default leaves it to pop-up-frames; never in the index's own window, whichever this is

Keys

  
Blank keeps the default. - binds nothing, and the
     keyboard button records the keys you press.

  
Check every key in your own Emacs before you settle on
     it. What this tool knows is a curated list — Emacs itself, your
     distribution's usual bindings, evil, and the PDF viewer you chose —
     and it cannot know your packages, your modules, or anything you have bound
     yourself. Nothing here is a guarantee that a key is free.

  
The way to find out takes a moment. Open a Diogenes entry
     and press C-h k then the key: Emacs names whatever holds it,
     or says it is undefined. In a scanned dictionary do the same — the
     answer differs there. For a sequence under a leader, press the leader and
     let which-key list what is taken.

Going between the windows and frames

  
These four are frame navigation. They matter most with
     frames, where each kind is in a frame of its own and
     C-x o cannot reach it — the key raises that frame and
     puts you in it. Within a single frame they move between windows just as
     usefully. Press one twice where there are two of a kind, an OLD page and a
     TLL page say, and you go to the second.

  
The scanned page has an option of its own rather than a place
     in the table below it, because that command does one thing the others do
     not: it prefers the page opened from the entry you are reading. Grouped
     here regardless, since what you mean by the key is the same.
